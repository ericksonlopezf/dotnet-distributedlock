## 2. Community Support Channels

### GitHub Issues
- **Bug Reports**: If you identify a reproducibly incorrect behavior, dialect incompatibility, or memory leak, please open a [Bug Report](https://github.com/ericksonlopezf/dotnet-distributedlock/issues/new?template=bug-report.md).
- **Feature Requests**: Propose enhancements, new database dialect adapters, or integration behaviors via a [Feature Request](https://github.com/ericksonlopezf/dotnet-distributedlock/issues/new?template=feature-request.md).

### GitHub Discussions
For architectural design advice, general usage inquiries, or sharing your production integration experiences, join the discussions on GitHub Discussions.
